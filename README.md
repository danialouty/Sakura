# Sakura 🌸

Sakura is a responsive e-commerce website for discovering and purchasing elegant Japanese flowers. I created it as my final project for an **Introduction to Web Development** course.

The project combines a clean visual design with interactive features to create a simple and enjoyable shopping experience. It also reflects my growth as a web developer and my appreciation for the beauty of Japanese flowers.

## Live Demo

Visit the website: [Sakura](https://danialouty.github.io/Sakura/)

## Features

- Browse a collection of Japanese flowers
- View individual flower details
- Add products to a shopping cart
- Create an account and log in
- Responsive layout for different screen sizes
- Firebase integration for storing and retrieving data
- Interactive user experience powered by JavaScript

## Built With

- HTML5
- CSS3
- JavaScript
- Firebase

## Project Structure

- `index.html` — Main landing page
- `*.html` — Flower, account, login, signup, and cart pages
- `*.css` — Website styling and responsive layouts
- `sakura.js` — Interactive functionality and Firebase integration
- `*.jpg` — Flower images
